# Explicit responsibility handoff

This is a procedure, not a passed report. See the [design](../../DESIGN.md) and [evidence format](../../docs/evidence/acceptance-template.md).

Use a synthetic task with an integrator, collaborators and unfinished assignments. Record task/assignment/session versions, effective epochs, capacity and exact artifacts.

Offer a voluntary integration handoff to an eligible active session. Enumerate every unfinished old-integrator claim as transfer, release or explicit continuation as worker within N. The receiver accepts the exact current offer. Owner-forced takeover uses the formal owner control and a reason, not an agent impersonation.

Negative cases: omit a disposition, exceed N, continue the old integrator as worker at N=0, use an old epoch, or have two sessions race for the same responsibility. Reject the whole invalid transition without partial changes or lost deliveries. A receiver already counted as worker must not be counted twice after becoming integrator.

For intake preparation, distinguish its owner from the designated future integrator. Test release, offered/accepted transfer, same-participant resume of an ended source and explicit owner takeover. Active or unknown source sessions are not automatically stolen. Old preparation mutations cannot convert after a valid transition.

Check the resulting owner, membership count, epochs and retained artifacts directly, then attempt an old-session mutation and require rejection. Session end does not release responsibility. Preserve real host witnesses for A08/A22/A35 and protocol race evidence for A02/A24.
