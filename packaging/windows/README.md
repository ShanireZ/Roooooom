# Windows platform status

Windows amd64 has development-host binary, private-control and native tray-dispatch checks. It is unsigned. Clean-user first use, real double-click/default browser and a minimum supported Windows version are not certified. Keep supported=false until matching evidence exists. The product-owned tray includes a reactivation entry; it does not control vendor hosts.

See [portable package instructions](../README.md) and [the platform matrix](../platforms.json).
